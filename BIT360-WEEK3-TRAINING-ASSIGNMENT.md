## Learning Objectives

After completing this training, students will:
1. Understand Veeam architecture and backup product components
2. Configure backup jobs for physical and virtual machines with appropriate retention policies
3. Analyze replication strategies (synchronous vs. asynchronous) and recovery point objectives (RPO)
4. Execute VM recovery procedures and single-file recovery operations
5. Implement cloud backup integration with Azure and other cloud storage solutions

---

## Training Content Topics

- Veeam architecture and backup product overview
- Installation and initial configuration of Veeam Backup & Replication
- Backup job types: full, incremental, differential, and reverse incremental
- Virtual machine backup and recovery procedures
- Data replication for disaster recovery and business continuity
- Cloud backup integration with Azure and cloud storage options
- Single-file and VM recovery operations
