### Confirmed Architecture for Lab 1B (Two Dell M1000e Blades, 4 NICs on A1/A2)
- **Virtual Switches (identical names on HV01 and HV02):**
  - `External Network` vSwitch on NIC1 (`A1`, `hn0`): Host management and firewall WAN (`10.0.[VLAN].2`)
  - `Lab LAN` vSwitch on NIC2 (`A2`, `hn1`): Firewall LAN (`192.168.[VLAN].1`)
  - Internal and Private switches are a learning step only.
- **Firewall Options:** OPNsense (primary, interfaces `hn0`/`hn1` on Hyper-V) and pfSense CE. FortiGate and Palo Alto removed (no free student versions).
- **VM Placement & Addressing:**
  - `HV01`: Firewall VM, `DC01`, `FS01` (all on `Lab LAN`; host `Lab LAN` management adapter `.21`, DNS to DCs, no gateway)
  - `HV02`: `DC02` (on `Lab LAN`; host `Lab LAN` management adapter `.22`, DNS to DCs, no gateway)
- **Build Sequence for 1B:** Hosts and switches → Firewall → `DC01` → `DC02` → `FS01` → Join hosts to domain → Live migration & replication.
- **Migration & Replication:**
  - Replication uses **Kerberos** (domain join only, allow HTTP 80).
  - Live migration uses **CredSSP** (initiate from source host; Kerberos constrained delegation is optional extension).
- **Deliverables to Add to 1B:** VM-count screenshot, firewall config backup (`System > Configuration > Backups` XML), and cross-host connectivity/internet verification screenshots.
