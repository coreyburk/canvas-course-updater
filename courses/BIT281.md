**Problem:** Week 3 SubHeader contained only 1 lecture note (RAM: Types, Channels & Configuration). BIOS/UEFI/POST diagnostic content was covered in Week 2's Motherboards note, leaving no dedicated Week 3 boot-focused lecture note.

**Solution:** Created new lecture note for Week 3.
- **Title:** Lecture Notes - Boot Process & POST Diagnostics
- **URL slug:** lecture-notes-boot-process-and-post-diagnostics-2
- **Location:** Course Outline and Lecture Notes module, Week 3 SubHeader, position 12 (before RAM note)
- **Status:** Unpublished (instructor-only), ready for review
- **Content outline:**
  - Boot sequence: 6-step progression (power-on → VRM ramp-up → BIOS init → POST → bootloader search → bootloader run → OS kernel load)
  - POST error codes: AMI beep code standard (1 short = pass, continuous = RAM error, 1 long + 2 short = video error, etc.)
  - Diagnosis by symptom: 5 common failure modes mapped to root cause (lights/fans/no display = RAM; power-cycle loop = BIOS critical error; "no bootable device" = storage/boot order; BSOD = OS corruption; random reboots = thermal/PSU/RAM under load)
  - Hands-on troubleshooting: RAM reseat procedure, CMOS clear procedure, boot order check
  - BIOS microcode updates: what they are, when to apply, risk vs. benefit
  - Current state (2024–2025): UEFI standard, Secure Boot and TPM 2.0 now Windows 11 mandatory, beep codes less relevant (no speakers) but diagnostic principle unchanged
  - Reference links: beep code standards, UEFI specs, TPM/Windows 11 docs

**Rationale:** Week 2's Motherboards note covers BIOS/UEFI architecture and Secure Boot. Week 3's entry page covers the boot sequence conceptually. The new dedicated note bridges boot diagnostics with POST symptom-to-cause mapping for hands-on troubleshooting and repair skills — the practical follow-up to conceptual understanding.
